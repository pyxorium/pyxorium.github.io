Mixtape lab

Tests for the Foundry's mixtape type: can this browser fetch your plyr.fm songs, do they join into one side, and how fast can it shrink them for phones?

1. Load your plyr.fm tracks

Only public information is read. Nothing is published or changed.

2. Run the tests on the ticked songs

Fetching is quick (it only asks for each file, then stops). Join and Convert download the songs in full, so start with two or three short ones, on Wi-Fi.

3. Results

Copy these and send them back.

MP3 encoding by lamejs, a JavaScript port of LAME, used unmodified under the GNU LGPL 3.0 (notes, the file itself).
